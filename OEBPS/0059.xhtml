 Nilpferden und Fischen nur so wimmelte. Foley sagte: »Geologische Be-

 Manchmal kann man ein System über lange Zeit belasten, belasten, belas-
 ten, und am Ende bringt ein einziger Tropfen das Fass zum Überlaufen.
Ist das Fass einmal übergelaufen, dann kann oder wird das System nie
 mehr in seinen ursprünglichen Zustand zurückkehren.
